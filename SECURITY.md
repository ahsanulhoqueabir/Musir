# Security Policy

## Supported versions
Only the latest release receives security fixes.

## Reporting a vulnerability
Please **do not** open a public issue for security problems. Instead, use GitHub's
[private vulnerability reporting](https://github.com/ahsanulhoqueabir/Musir/security/advisories/new)
or email **tritiyobit@gmail.com** with details and steps to reproduce.

You can expect an acknowledgement within a few days and a fix or mitigation plan as soon as practical.
